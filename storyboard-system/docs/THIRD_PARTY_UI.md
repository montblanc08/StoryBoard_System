# UI component attribution

FrameForge's UI reuses Material Web 2.4.1 (`@material/web`, Apache-2.0) and its
Lit dependencies (BSD-3-Clause). Their unmodified license texts are distributed
under `static/vendor/*-LICENSE.txt`. The build also emits linked legal notices.
These third-party components retain their own licenses independently of the
FrameForge application license.

The creative-board editor and its 2D furniture, camera and light symbols are
original implementation and SVG geometry. No 酷家乐 source code or proprietary
asset library is included. Light cones are planning illustrations, not calibrated
photometric simulation.
